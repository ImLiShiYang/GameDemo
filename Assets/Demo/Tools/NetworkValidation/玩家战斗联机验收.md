# 玩家战斗操控与表现联机迁移

范围已确认：本轮不迁移经验球、升级三选一和 Buff 拾取。

## 已接入的链路

| 功能 | 客户端 | 服务器 |
| --- | --- | --- |
| WASD / 鼠标瞄准 | 预测移动；原瞄准死区、瞄准线、准心、枪械旋转与双手 IK | 同一移动算法，原场景移动速度与加速度 |
| 行走动画 | 根据世界移动方向转换为角色局部 MoveX/MoveY，支持横移和倒走 | 快照携带移动方向 |
| 左键射击 | Fire 动画状态；收到开火事件后播放原枪口粒子、音效 | 原武器伤害、间隔、弹速、寿命；多发、扩散、穿透属性；权威命中 |
| 空格翻滚 | 缓存单次按下、预测和重演；原 Roll 动画、武器挂手与 IK 切换 | 固定 Tick 位移、动作互斥、冷却、无敌帧、静态场景碰撞 |
| R 冲击波 | 原预警特效跟随施法者；冷却 HUD | 原 Lua 配置，蓄力结束时范围判伤、打断、每玩家冷却 |
| F 穿透射线 | 原射线特效，使用服务器确定的起点/方向；冷却 HUD | 原 Lua 配置，一次命中多个敌人，同一敌人只判伤一次 |
| 受击 / 死亡 | Hit/Dead 动画、IK/武器姿势、血量 HUD；不运行单机销毁和结算 | 生命与护盾状态、翻滚免伤、硬直、死亡后禁止操作 |

翻滚键读取原场景配置（当前为空格），保留空格兼容入口。本轮翻滚不是逐帧复制 Animator Root Motion：Running Dive Roll 的持续时间量化为 15 个 20 Hz Tick，位移为 4 米；可在 PlayerMovementSimulation 调整。原动画事件在联机模式下不能改变权威无敌/结束时间。

静态碰撞使用 CharacterController 的胶囊尺寸做扫掠与滑动，预测和重演使用相同逻辑；不预测动态刚体、敌人推挤、平台移动和完整台阶/重力物理。现有服务器敌人 AI 仍是追击版本，本轮没有新增敌人攻击。玩家受伤入口为 ServerPlayerManager.ApplyPlayerDamage，网络模式的 Health.TakeDamage 会路由至该入口。

## 自动化检查

从项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File Assets/Demo/Tools/NetworkValidation/Test-NetworkPlayerMigration.ps1
```

检查实际项目脚本编译，以及生产代码的移动/翻滚约束、动作恢复重演、输入和快照序列化、技能事件字段、非法状态拒绝。脚本默认清理本次产生的临时二进制文件。这里不包含 Unity 原生物理或实际双客户端画面测试。

## 双客户端验收

协议从 5 升为 6，必须使用同一次重新构建的服务器和两个客户端；旧包不兼容。无需手工挂新增运行时组件。

1. 启动服务器和两名客户端，等待战斗阶段；两名玩家都显示瞄准线，只有本地玩家显示准心。远程玩家的线随同步朝向变化，不读取当前窗口鼠标；翻滚、受击和死亡期间隐藏。
2. 鼠标固定朝向，分别按前后左右；两端模型应使用前进/后退/横移动画，枪与双手随瞄准方向变化。
3. 持续射击并转向；两端均应看到子弹和枪口效果、听到开枪声音，无客户端额外生成的单机伤害子弹。
4. 快按空格、连按空格、移动时翻滚、原地翻滚；动作不能漏掉或因为补帧重复，翻滚中不能开枪/释放技能，墙前应停止/滑动。
5. 玩家 1 按 R/F，玩家 2 随即按同技能：各自正常施法，冷却独立；冷却未结束时服务器拒绝再次施放。
6. 冲击波预警在施法者附近跟随，延迟后判伤；射线穿透多个敌人，各命中一次，两端效果方向一致。
7. 用服务器伤害入口测试受击、翻滚无敌和死亡：客户端不能自行扣血；血量 HUD 跟随快照，死亡后移动/射击/翻滚/技能全部被拒绝。
8. 增加延迟，观察翻滚中校正与结束恢复：原动画事件不能提前结束网络翻滚；重演不会重复播放枪声、技能特效或造成伤害。
9. 客户端失焦或打开本地暂停界面：上传中性输入；其他玩家和服务器仍继续，关闭界面后无积压的翻滚/技能按下。
10. 单机启动回归：原移动、Root Motion 翻滚、动画事件、技能和本地伤害路径保持单机模式运行。
