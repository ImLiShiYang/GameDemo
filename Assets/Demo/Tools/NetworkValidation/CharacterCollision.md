# 联机角色碰撞接入与验收

## 已接入

- `NetworkCharacterMotor` 是独立的逻辑身体，使用 CharacterController.Move、重力、落地状态、坡面及台阶。玩家显示对象上的旧 CharacterController 保持禁用是正常现象，无需手动添加第二个胶囊或 Rigidbody。
- 运行时在网络根节点下创建 `NetworkBody_<EntityId>`。玩家身体半径/高度为 0.5/2，普通敌人为 0.45/2.4，Boss 为 0.9/4.4。参数集中在 NetworkCharacterShape.ForPrefab；重力、落地速度、终端速度集中在 Motor。
- 角色接触采用独立逻辑胶囊水平扫掠和滑动，不参与台阶攀爬、不推挤。移动身体之间忽略原生 CC 接触；场景阻挡仍交给 CC。角色移动后再次检查接触，防止墙角或坡面产生的额外侧移穿人。
- 翻滚撞墙/撞人仅限制位移，不提前终止翻滚、无敌或冷却。死亡立即退出角色阻挡；断线与 Despawn 清理身体。
- 客户端逻辑身体与插值模型分离；远程碰撞代理使用权威位置。每份输入保留当时的碰撞上下文，重演结束或异常时恢复当前代理状态。重演不播放战斗表现、不判伤。
- ServerSimulationLoop 是唯一游戏 Tick 订阅者，负责输入/生成、按 EntityId 移动、战斗、投射物、流程结算、快照。仍为 20 Hz 模拟/10 Hz 快照。
- 无合法出生点时延后生成，不生成重叠角色；玩家真正生成后才开始双人倒计时。敌人模型改为脚底根节点，显示模型上移半身高。
- 玩家快照增加 VerticalVelocity/Grounded，协议版本升到 **7**。客户端、服务器必须一起重新构建；旧版本程序不可混用。
- 新身体不会挡住自己的瞄准射线或被投射物的场景碰撞分支当作墙；原有服务器伤害规则不变。

## 自动化验证

在项目根目录执行：

```powershell
& Assets/Demo/Tools/NetworkValidation/Test-NetworkPlayerMigration.ps1
& Assets/Demo/Tools/NetworkValidation/Invoke-UnityNetworkChecks.ps1 -Action Compile
& Assets/Demo/Tools/NetworkValidation/Invoke-UnityNetworkChecks.ps1 -Action Physics
```

第二、三条通过当前项目已有的本机编辑器桥接执行，需要编辑器打开且处于非播放状态。也可在编辑器菜单选择 `Tools > Network Validation > Run Character Physics Checks`。

物理测试仅创建临时附加场景，不保存或修改原场景；完成后关闭临时场景并恢复原活动场景。结果写入 `Temp/NetworkCharacterPhysicsChecks.txt`。

2026-09-04 验证结果：

- 游戏脚本编译及编辑器编译成功。
- **39 项协议/动作检查通过**，包括落地/下落状态序列化、非法垂直速度拒绝、翻滚和动作重演。
- **36 项 Unity 原生物理/预测检查通过**：重力、滑墙、墙角、翻滚阻挡、双角色对向移动、不推人、不爬人、死亡/离场清理、历史上下文恢复、台阶、可行走/过陡坡面、占用出生点、Boss 身体尺寸。
- 原生检查中包含两套客户端预测与服务器身体在模拟 100–250 ms 延迟/抖动快照下的收敛、显示位置与逻辑位置隔离、128 条输入缓冲区溢出及恢复。
- 主场景已打开时还检查两个玩家与 Boss 的实际出生位置；没有打开带玩家的场景时会跳过这 3 项，基础检查数为 33。

延迟检查在同一编辑器内使用三套相隔的物理区域和实际协议编解码，不是三个独立进程的 TCP 或画面验收。

## 双窗口手动验收（尚未完成）

1. 重新构建同一份 v7 程序，启动服务器和两个客户端。确认双方落在地面，控制的身体与显示模型各只有一份。
2. 各自直撞墙、斜向贴墙、挤墙角、通过窄通道、走台阶和坡面，再向墙翻滚。不能穿墙或长期陷地。
3. 两个玩家相向行走/翻滚；一个站立，另一个或敌人接近；靠墙被多个角色围住。接触应停止或滑动，不能穿人、推人或爬上身体。
4. 分别移动并射击、翻滚、施放两个技能。检查动画、枪口、音效、双方瞄准线；远程玩家仍然没有准心。
5. 重复接触操作并观察校正指标。允许移动角色接触时有服务器校正，但输入停止并收到最新状态后应收敛，不能持续来回拉扯。
6. 角色死亡、客户端断线后再次经过原位置，确认没有隐形阻挡；重新连接后检查出生位置。

本次不包含跳跃、移动平台、刚体推挤、布娃娃、掉落伤害、经验球、升级或 Buff 迁移；不是全世界回滚。未来的远程输入未知，动态接触仍由服务器最终裁决。
